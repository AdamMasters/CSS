# Exemplars

This folder holds **real, anonymised student submissions** for the tasks in `assessment/tasks/`, kept as a growing reference library across years and classes.

## Convention

Add one subfolder per task, per cohort, per grade band — never a real student's name:

```text
exemplars/
├── task-02/
│   ├── sics-2026-cohort-a-secure/
│   │   ├── index.html
│   │   ├── styles.css
│   │   └── notes.md        ← what this response does well / where it falls short
│   └── sics-2026-cohort-a-exceptional/
└── task-04/
    └── sics-2027-cohort-b-secure/
```

- `notes.md` in each exemplar folder should briefly explain, against the matching mark scheme, why the piece sits at that level — this is what makes the exemplar useful for standardising marking, not just displaying finished work.
- Strip names, emails and any identifying detail before adding a submission here; use a level label (e.g. `-developing`, `-secure`, `-exceptional`) instead of a grade or student identifier.
- Get student/parent consent before committing coursework, per your school's data policy.

No exemplars are included yet — this file is the placeholder that establishes the structure ready for the first cohort's work.
