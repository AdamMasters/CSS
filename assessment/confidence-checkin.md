# Confidence Check-in — Printable Self-Assessment

**Use:** at the start of the Unit 4 project (before Task 01), and again before submission (after Task 06), so students can see their own progress.
**Time:** 5–10 minutes
**Not for marking** — this is a self-awareness tool, not assessed work. Encourage complete honesty: an accurate low score is more useful than an inflated high one.

---

## Instructions for students

For each CSS topic below, circle a number from **0 to 10**:

- **0–3** — "I've never really used this" / not confident at all
- **4–6** — "I can use this with the notes/playground open"
- **7–8** — "I can use this independently"
- **9–10** — "I could teach this to someone else"

Then circle **Y** or **N** for whether you think you're likely to actually use this topic in your own website.

## Teacher notes

- An interactive, auto-saving version of this same check-in is built into the app itself as **Module 11 — Confidence Check-in** (a simple list of sliders, one per topic, saved in the student's browser) — use whichever format suits the lesson: paper for a quick low-tech starter/plenary, or the in-app version if students are already at a screen.
- Running this **twice** (before Task 01 and after Task 06) gives a simple before/after confidence comparison that works well as evidence in a student's evaluation for Task 06, without being a mark scheme item itself.
- A class-wide pattern of low confidence on one topic is a useful signal to re-teach that module before moving further into the project tasks.
